Open Access Internet Services

We provide the following services for free to the internet community:

Retro Client/Server

Hotline Connect Server
Client/server protocol popular in the mid-late '90s. Chat, message boards, and file sharing. Similar to a GUI BBS.
  • ADDRESS: hotline.hco3.xyz
  • PORT: 500 (default)
  • LOGIN: guest (default)
Haxial KDX Server
A newer protocol from the same era by the creator of Hotline. Includes everything Hotline has, with a multitude of additions.
  • ADDRESS: kdx.hco3.xyz
  • PORT: 10700 (default)
  • LOGIN: guest (default)

Neither servers require an account. Accounts are available if you expect to hang out regularly and would like the customization.

Chat

Internet Relay Chat (IRC)
Still-popular early chat (as well as early file sharing) protocol. An example of federation before it was known as that. Independent IRC servers link the form networks.
